# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Versions apply per implementation. The **algorithm** is versioned separately and
independently, by spec version: see [`spec/SPEC.md`](spec/SPEC.md). A change in
observable output requires a new spec version and a new set of canonical
vectors, never a silent bump.

## [0.1.0] - 2026-08-03

Initial release. Spec v1, frozen.

### Added

- `spec/SPEC.md` - normative specification of the permutation, key schedule,
  round function, and base62 encoding. Frozen at v1.
- `vectors/vectors.json` - 61 canonical known-answer vectors covering 5 distinct
  keys, the domain edges, ordinary values, and a run of consecutive ids
  demonstrating non-enumerability. Generated by the reference implementation.
- `impl/rust` - reference implementation. `Arxid::new(key: u64)` with
  `obfuscate` / `deobfuscate` / `obfuscate_str` / `deobfuscate_str`, plus the
  free functions and the base62 layer. `#![forbid(unsafe_code)]`, `no_std`
  capable, features `std` / `alloc` / `encoding` / `zeroize` (default on) and
  `wasm` (default off).
- `impl/ts` - native TypeScript port. ESM, zero runtime dependencies, key as
  `bigint`. Validated against the same vectors.
- CI validating both implementations against the canonical vectors, plus
  `no_std` and `wasm32-unknown-unknown` build checks.

### Notes

- `spec/SPEC.md` section 2.1 documents that the key schedule maps `key` and
  `!key` to the same permutation, making the effective key space 2^63. This is
  a property of the frozen algorithm, not a defect, and is pinned by tests in
  both implementations.
- The permutation and base62 encoding originate in
  [quark](https://github.com/lucasolopes/quark) and are relicensed here under
  MIT by the copyright holder. arxid contains no AGPL-licensed code.
